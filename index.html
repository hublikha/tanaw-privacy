Tanaw

See what any website is actually made of — in one click.

tanaw (Tagalog): to view; the vista; what you see looking out over something.

Tanaw is a browser extension that turns any domain into a complete diagnostic report: who hosts it, its IP address and network operator, DNS records, SSL certificate status, and the technologies it is built with — plus security, SEO, accessibility and performance checks. Built for developers, hosting support agents and web agencies.

What it shows

Hosting

Host, IP, network operator and CDN — correlated across six signals, and honest when an origin is hidden behind a proxy rather than naming the proxy as the host.

DNS

A, AAAA, CNAME, NS, MX, TXT, CAA and SOA records, plus who runs the zone, who handles email, and whether SPF, DKIM and DMARC are configured correctly.

SSL

Certificate authority, expiry, covered domains and HSTS — separating what the browser verified from what came from public certificate transparency logs.

Technology

Over 150 signatures across CMS platforms, frameworks, hosting, analytics and AI tools, each with a version, a confidence score and the evidence behind it.

Plus security header analysis, SEO checks with a search-result preview, accessibility testing with real contrast measurement, Core Web Vitals, and a privacy report showing which third parties receive your visitors' data.

Check any domain

Type a domain into the search box to diagnose a site you are not currently visiting — built for support agents working on a customer's website while looking at their own dashboard. Every fact has a copy button, and a full scan takes well under a second.

Privacy

Page content is processed on your device and is never sent to Hublikha. Technology, security, SEO, accessibility and performance checks run locally. If you explicitly check another domain, your browser contacts that target domain directly. Optional DNS, registrar, IP and certificate lookups are disabled by default; when enabled, only the domain name or IP address needed for the lookup is sent to the named public provider. Never page content, never browsing history, never analytics.

Common questions

Why does it need access to websites?
Tanaw can inspect any HTTP or HTTPS site you choose, so its site access cannot be narrowed to a fixed domain list. It uses that access for the site you actively analyze, for explicit remote-domain checks that you start, and, if you enable optional lookups, for requests to the named public lookup providers. It does not request browser cookie access or collect your browsing history.
Why is some data missing until I reload the page?
Response headers and the server IP are captured as the page loads. If the tab was already open before the extension started, that moment has passed — reload once and it appears.
Why can't it read the SSL certificate directly?
No browser extension API exposes the certificate of the page you are viewing. Chrome simply does not offer it. Tanaw reads public Certificate Transparency logs instead, and labels clearly which facts came from the live connection and which came from the logs.
Does it work offline?
Yes. Technology detection, security headers, SEO, accessibility and performance are all computed locally and work with no network at all. Only DNS, registrar, IP ownership and certificate details require lookups, and those are optional.
